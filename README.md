# fiskov tools

A collection of browser-based utilities, hosted at **https://fiskov.github.io**

## Tools

### 🔧 [HEX File Merger](https://fiskov.github.io/hex_merger/)
Merge up to 4 Intel HEX / BIN files into a single binary or HEX output.
- Drag-and-drop or browse for `.hex` / `.bin` files
- Visual memory map with overlap detection
- Configurable filler byte, output filename, and BIN trim option
- Export as `.bin` or Intel HEX (with optional STM32 base address)

### 📁 [Folder Word Counter](https://fiskov.github.io/words_count/)
Browse a folder and count words across e-book files (fb2, epub, txt, docx…).

---

> All tools run entirely in the browser — no server, no uploads.
